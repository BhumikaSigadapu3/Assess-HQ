# Screenshots for Assess HQ README

Add PNG or JPEG files here. Paths must match the root [README.md](../../README.md) so images render on GitHub.

## Required filenames

| File | What to capture |
|------|-----------------|
| `auth-login.png` | Login or signup page |
| `candidate-home.png` | Candidate dashboard home |
| `candidate-assessments.png` | Assessments list / registration |
| `candidate-exam-runner.png` | Active exam session (MCQ or coding) |
| `candidate-coding.png` | Coding workspace / practice |
| `candidate-interviews.png` | Candidate interviews page |
| `candidate-resume-analyzer.png` | Resume analyzer (candidate) |
| `recruiter-home.png` | Recruiter home / metrics |
| `recruiter-assessments.png` | Assessments list or results / shortlist |
| `recruiter-interviews.png` | Interview list and detail modal |
| `admin-dashboard.png` | Admin dashboard |

## Tips

- Use a consistent theme (light or dark).
- Crop or blur sensitive emails if needed.
- Width around 1280–1600 px keeps the README readable.
- On Windows, use Snipping Tool or Win+Shift+S, then save into this folder.

## Quick test

After adding files, open README on GitHub or use a Markdown preview that resolves relative paths from the repo root.
